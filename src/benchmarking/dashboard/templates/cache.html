Cache Architecture

The translation system uses a three-level translation memory (TM) cache:

L1 Cache: Segment-level exact matches
L2 Cache: Fuzzy matches and variations
L3 Cache: Model predictions and embeddings

Cache effectiveness is measured by:

  • Hit Rate: cache_hits / (cache_hits + cache_misses)
  • Speedup: uncached_time / cached_time
  • Memory Efficiency: saved_tokens / cache_size_mb
