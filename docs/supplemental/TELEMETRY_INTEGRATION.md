# Telemetry Integration (TEL-04)

## Overview

The hugo-translator project has been integrated with the TEL-03 telemetry platform to track translation metrics, token usage, cache performance, and file operations.

## Features Implemented

### 1. Token Tracking

- **Input Tokens**: Tokens sent to the translation model
- **Output Tokens**: Tokens generated by the model
- **Cached Tokens**: Estimated tokens saved via Translation Memory hits
- **Total Tokens**: Total tokens processed (cached + translated)

### 2. File Operation Tracking

- **Files Added**: New `.md` files created
- **Files Updated**: Existing `.md` files overwritten
- **Bytes Written**: Total bytes written to `.md` files
- **TM Entries**: Translation Memory entries stored

### 3. Cache Performance Metrics

- **TM Hit Rate**: Percentage of segments found in cache
- **Token Cache Rate**: Percentage of tokens served from cache
- **Layer Breakdown**: L1 (in-memory), L2 (persistent), L3 (semantic) hit counts

### 4. Session Tracking

- Each translation operation gets a unique `run_id`
- Batch operations aggregate metrics across all files
- Full context preserved (source files, target languages, etc.)

## Configuration

### Enable/Disable Telemetry

Telemetry is **enabled by default**. To disable it:

**Option 1: Environment Variable**
```bash
export HUGO_TRANSLATOR_TELEMETRY_ENABLED=false
```

**Option 2: Code Configuration**
```python
from translation_engine import TranslationEngine

engine = TranslationEngine(
    config_service=config,
    tm=tm,
    model_loader=loader,
    enable_telemetry=False  # Disable telemetry
)
```

### Configure Telemetry Settings

Set these environment variables to configure the telemetry platform:

```bash
# Base directory for telemetry data (default: D:\agent-metrics)
export AGENT_METRICS_DIR=C:\custom\metrics

# API configuration (optional - for remote posting)
export METRICS_API_URL=https://your-api.example.com/metrics
export METRICS_API_TOKEN=your-secret-token
export METRICS_API_ENABLED=true

# Agent owner identifier
export AGENT_OWNER=your-username
```

## Usage

### Automatic Tracking

Telemetry tracking happens **automatically** when you use the TranslationEngine:

```python
from translation_engine import TranslationEngine

# Initialize engine (telemetry enabled by default)
engine = TranslationEngine(config, tm, loader)

# Translate a file - telemetry tracked automatically
result = engine.translate_file(
    site_id="my-site",
    file_path=Path("content/example.md"),
    target_langs=["es", "fr"]
)

# Check the stats
print(f"Tokens input: {result.stats.tokens_input}")
print(f"Tokens cached: {result.stats.tokens_cached}")
print(f"Cache hit rate: {result.stats.tm_hit_rate:.1%}")
print(f"Files added: {result.stats.md_files_added}")
```

### Batch Translation

```python
# Translate entire directory - aggregated telemetry
result = engine.translate_directory(
    site_id="my-site",
    directory=Path("content/"),
    target_langs=["es", "fr"],
    recursive=True,
    parallel=True
)

# Get aggregated stats
agg_stats = result.aggregate_stats
print(f"Total tokens processed: {agg_stats.tokens_total}")
print(f"Total files: {result.total_files}")
print(f"Successful: {result.successful_files}")
```

## Telemetry Data Storage

Telemetry data is stored in three locations:

1. **NDJSON Files**: `{AGENT_METRICS_DIR}/raw/{date}/hugo-translator.ndjson`
   - Raw event logs in newline-delimited JSON format
   - One file per day

2. **SQLite Database**: `{AGENT_METRICS_DIR}/db/telemetry.sqlite`
   - Structured storage for querying and analysis
   - Tables: `agent_runs`, `agent_events`

3. **API Endpoint** (if enabled): Remote posting to configured API URL

## Viewing Telemetry Data

### Query SQLite Database

```bash
# Open the database
sqlite3 D:\agent-metrics\db\telemetry.sqlite

# View recent translation runs
SELECT
    run_id,
    agent_task,
    started_at,
    duration_seconds,
    json_extract(custom_metrics, '$.tokens_total') as tokens_total,
    json_extract(custom_metrics, '$.tm_hit_rate') as hit_rate
FROM agent_runs
WHERE agent_id = 'hugo-translator'
ORDER BY started_at DESC
LIMIT 10;
```

### Read NDJSON Files

```bash
# View today's telemetry events
cat D:\agent-metrics\raw\{YYYY-MM-DD}\hugo-translator.ndjson | jq .
```

### Python API

```python
from telemetry.database_reader import TelemetryReader

reader = TelemetryReader()

# Get recent runs
runs = reader.get_runs(
    agent_id="hugo-translator",
    limit=10
)

for run in runs:
    print(f"{run.agent_task}: {run.custom_metrics.get('tokens_total')} tokens")
```

## Metrics Tracked

| Metric | Type | Description |
|--------|------|-------------|
| `tokens_input` | int | Input tokens to model |
| `tokens_output` | int | Output tokens from model |
| `tokens_cached` | int | Tokens from cache (estimated) |
| `tokens_total` | int | Total tokens processed |
| `total_segments` | int | Total translation segments |
| `tm_hits` | int | Translation Memory hits |
| `l1_hits` | int | L1 cache hits (in-memory) |
| `l2_hits` | int | L2 cache hits (persistent) |
| `l3_hits` | int | L3 cache hits (semantic) |
| `translated_segments` | int | New translations via model |
| `md_files_added` | int | New `.md` files created |
| `md_files_updated` | int | Existing `.md` files updated |
| `bytes_written_md` | int | Bytes written to `.md` files |
| `tm_entries_stored` | int | TM entries stored |
| `tm_hit_rate` | float | TM hit rate (0-1) |
| `token_cache_rate` | float | Token cache rate (0-1) |
| `duration_seconds` | float | Operation duration |

## Architecture Changes

### Modified Files

1. **`src/translation_engine/models.py`**
   - Extended `TranslationStats` with token and file operation metrics

2. **`src/model_runtime/loader.py`**
   - Added `translate_with_token_counts()` to `HuggingFaceBackend`
   - Token counting using `.numel()` on input/output tensors

3. **`src/translation_engine/engine.py`**
   - Added `estimate_token_count()` helper function
   - Token tracking in `_translate_to_language()`
   - File operation tracking (add vs. update)
   - TM entry storage tracking
   - Telemetry hooks in `translate_file()` and `translate_directory()`

4. **`src/observability/telemetry_integration.py`** (NEW)
   - `TranslationTelemetry` class for integration
   - Context managers for tracking sessions
   - Graceful degradation if telemetry unavailable

### Backward Compatibility

- **100% backward compatible**: All changes are additive
- Telemetry can be disabled without affecting functionality
- Existing code continues to work unchanged
- New metrics are optional and don't break APIs

## Troubleshooting

### Telemetry Not Working

1. **Check if telemetry is enabled**:
   ```python
   print(engine.telemetry.is_available())
   ```

2. **Check environment variables**:
   ```bash
   echo $HUGO_TRANSLATOR_TELEMETRY_ENABLED
   echo $AGENT_METRICS_DIR
   ```

3. **Check storage directories exist**:
   ```bash
   python scripts/setup_storage.py
   ```

4. **Check logs for errors**:
   - Telemetry errors are logged as warnings and don't break translation

### Telemetry Overhead

- **Minimal overhead**: ~1-2% performance impact
- Token counting uses existing tensors (no extra computation)
- File tracking uses simple checks before writes
- Telemetry writes are non-blocking (async if possible)

### Disabling Telemetry

If telemetry causes any issues, disable it:

```bash
export HUGO_TRANSLATOR_TELEMETRY_ENABLED=false
```

Or in code:

```python
engine = TranslationEngine(
    config, tm, loader,
    enable_telemetry=False
)
```
