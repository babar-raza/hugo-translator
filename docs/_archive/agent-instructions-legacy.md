# Agent Instructions

Rules
1. Use a repo-local Python virtual environment for all dependencies, including torch. Do not install packages globally.
2. Prefer existing dependency files (pyproject.toml/requirements/) and keep dependency changes minimal and explicit.
3. Keep edits scoped to the task; avoid touching unrelated files.
4. When changing code, run relevant tests or note clearly if tests were not run.
5. Follow existing formatting and conventions; avoid reformatting unrelated code.
6. try to reuse and adapt instead of inventing or creating new code
7. If you are unsure, ask for clarification before proceeding.
