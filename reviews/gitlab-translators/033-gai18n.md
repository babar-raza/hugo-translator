## Purpose
A GitLab AI agent for internationalization that listens to GitLab webhooks, translates content using LLM, and creates merge requests with translations. Supports two modes: Hugo (Markdown content files with template-based extraction and placeholder IDs) and NgJson (JSON i18n files for Angular applications). Webhook-driven, event-based architecture.

## Key Implementation Details
- Webhook-driven: listens to GitLab push events, triggers translation on content changes.
- Creates merge requests with translated content rather than pushing directly.
- Per-repo configuration via `.gai18n/config.json` with `chunkSize` and `translationRetryCount`.
- Dual-mode: Hugo (Markdown) and NgJson (Angular JSON i18n).
- Template-based extraction: replaces non-translatable content with placeholder IDs before sending to LLM.
- NUKE build system with Nix flake support.
- CLAUDE.md present indicating AI-assisted development.

## Strengths
- Most architecturally mature Hugo-aware translator in the GitLab set.
- Comprehensive test suite (12+ test classes) covering core features.
- Merge request workflow (not direct push) is safer for production.
- Per-repo configuration is flexible and scalable.
- Placeholder ID system for protecting non-translatable content.
- Clean C# architecture with feature-based folder organization.
- Configurable chunking and retry.

## Weaknesses and Gaps
- No AST-based parsing (template/regex approach).
- No formal glossary/terminology system.
- No MT model fallback (LLM only).
- No multi-layer translation memory (single storage layer).
- No validation suite comparable to hugo-translator's 10 validators.
- Default README is GitLab template (not fully customized beyond setup guide).
- No explicit dry-run mode.

## Relevance to hugo-translator
**Classification:** Highly relevant

The most architecturally comparable project to hugo-translator in the GitLab set. ## Production Risk Notes
- Webhook listener requires running service (not just CI job).
- GitLab API token required for MR creation.
- No rate limiting on LLM calls beyond retry logic.
- Translation storage persistence mechanism unclear from source inspection.

## Final Recommendation
