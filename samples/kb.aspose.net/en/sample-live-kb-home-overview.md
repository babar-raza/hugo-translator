## Purpose of the Knowledge Base

The Aspose for .NET knowledge base provides task-focused articles that complement the main documentation.  
While the docs portal explains concepts and APIs in depth, KB articles focus on concrete scenarios such as adding images to a Word document or exposing a watermarking API.

The KB landing pages introduce available product categories—Words, Cells, PDF, HTML, and others—and link to articles that walk through specific workflows.  
This structure helps developers quickly find step‑by‑step guidance for common implementation tasks.

You can start exploring KB content from the main entry point at [kb.aspose.com](https://kb.aspose.com/).

## Relationship to Product Documentation

KB articles frequently reference the main product documentation on [docs.aspose.com](https://docs.aspose.com/).  
For example, an article about adding images to Word documents in C# will link back to Aspose.Words API reference and conceptual guides.

This cross‑linking ensures that developers can move from a focused how‑to to broader API coverage when needed.  
It also keeps KB content concise while still providing access to the full set of options and configuration details.

Examples of this relationship can be seen in Word‑related KB topics under `content/kb.aspose.net/words/en/`, which draw from both KB and docs content.

## Types of Articles in the KB

The KB includes tutorials, troubleshooting guides, deployment checklists, and best practices.  
Word‑focused examples include articles on adding images, inserting watermarks, and assembling documents with templates.

Other product areas cover similar patterns—forinstance, exposing REST APIs for PDF manipulation or optimizing spreadsheet processing with Aspose.Cells.  
These articles are designed to be copy‑paste friendly and often include prerequisites, step lists, and code snippets.

Representative Word KB articles are stored under `content/kb.aspose.net/words/en/` and are reflected in the live site content on [kb.aspose.com](https://kb.aspose.com/).
