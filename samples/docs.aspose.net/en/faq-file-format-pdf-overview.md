## Format Basics

**Q1. What is PDF and why was it created?**  
PDF (Portable Document Format) is a file format introduced by Adobe to provide a consistent way to represent documents across platforms and devices.  
The **PDF File Format** article explains that its core goal is to preserve layout, fonts, and graphics regardless of where the document is viewed.

**Q2. What types of content can a PDF contain?**  
According to the file format documentation, PDFs can contain text, vector graphics, images, hyperlinks, form fields, rich media, digital signatures, attachments, metadata, and even 3D objects.  
This breadth of content makes PDF suitable for contracts, manuals, interactive forms, and technical documentation.

## Technical and Compliance Considerations

**Q3. How is a PDF file structured internally?**  
The reference article describes a PDF as containing a header, body with objects, a cross‑reference table, and a trailer.  
This structure enables efficient random access to objects, incremental updates, and reliable parsing by compliant PDF readers.

**Q4. Does PDF support accessibility features?**  
Yes. The documentation notes that PDF can comply with accessibility standards like PDF/UA when properly tagged.  
Tagged PDFs include structural information that assistive technologies can use to present content to users with disabilities.

## Working with PDFs in Code

**Q5. Which Aspose products work with PDF files?**  
The file format and product documentation highlight Aspose.PDF for .NET as the primary library for creating, editing, and converting PDFs.  
Other product families, such as Aspose.Words and Aspose.Cells, can also export to PDF as part of document and spreadsheet workflows.

**Q6. Where can I find code examples?**  
PDF‑related articles on [docs.aspose.com](https://docs.aspose.com/file-formats/pdf/) and product‑specific sections link to sample projects and code snippets.  
These examples demonstrate tasks like PDF creation, optimization, and format conversion in C# and other supported languages.
