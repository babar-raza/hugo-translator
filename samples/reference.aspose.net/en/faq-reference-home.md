## General Questions

**Q1. What is the Aspose High Code reference portal?**
It is an API reference site that documents classes, methods, properties, and other members for Aspose libraries across supported platforms.
The portal is introduced in `content/reference.aspose.net/home/en/_index.md` and is accessible at [reference.aspose.net](https://reference.aspose.net/).

**Q2. How does the reference portal relate to the main docs site?**
The reference portal focuses on API signatures and detailed member descriptions, while the docs site provides conceptual guides and how-to articles.
Many docs pages link to reference content so developers can see exact type signatures.

## Navigation and Structure

**Q3. How is content organized in the reference portal?**
Content is grouped by product family and then by namespace, with pages for each type (class, interface, enum, and so on).
Within a type page, sections cover inheritance, derived types, implemented interfaces, and member lists.

**Q4. Can I browse references for different languages?**
Yes.
The portal includes references for .NET and other platforms where available, typically arranged in product-specific sections.
Language-specific tabs or sections indicate when multiple platforms are documented.

## Updates and Versioning

**Q5. How often is reference content updated?**
Reference pages are updated as new versions of the libraries are released, ensuring that API signatures match current versions.
Assembly version information, such as the numbers shown in type pages, helps developers confirm which version a reference applies to.
