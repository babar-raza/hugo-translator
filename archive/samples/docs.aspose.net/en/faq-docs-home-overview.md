## General Questions

**Q1. What products are covered on the Aspose documentation portal?**  
The portal covers all major Aspose product families, including Words, Cells, PDF, Slides, Email, Tasks, HTML, Imaging, BarCode, OCR, and others.  
This is evident from the product navigation visible on [docs.aspose.com](https://docs.aspose.com/), where each family has its own section.

**Q2. Which programming platforms are supported in the docs?**  
Most content focuses on .NET, but many products also include documentation for Java, C++, and cloud APIs.  
Platform‑specific navigation menus on the docs site indicate which APIs and examples apply to each technology.

## Structure and Navigation

**Q3. How is the documentation organized?**  
Each product section is typically divided into Getting Started, Developer Guide, File Format Support, and API Reference areas.  
Landing pages similar to `content/docs.aspose.net/home/en/_index.md` introduce these sections and provide links to common tasks.

**Q4. Where can I find example code?**  
Many articles include inline C# and VB.NET snippets as well as links to GitHub repositories that host complete examples.  
These links are surfaced throughout guides such as licensing, document manipulation, and file conversion topics on [docs.aspose.com](https://docs.aspose.com/).

## Updates and Localization

**Q5. How often is the documentation updated?**  
The documentation is updated alongside product releases, with new APIs, samples, and migration notes added as needed.  
Release notes and version‑specific sections in the docs highlight recent additions.

**Q6. Is localized documentation available?**  
Yes. The repository structure and live site both show localized variants for multiple languages, with language‑specific folders and URLs.  
Where available, localized pages mirror the structure and content of the English documentation on [docs.aspose.com](https://docs.aspose.com/).
