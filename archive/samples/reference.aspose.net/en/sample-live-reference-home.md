## Purpose of the Reference Portal

The Aspose High Code reference portal provides API reference documentation for .NET, Java, and other platforms across the Aspose product families.
It complements conceptual documentation by offering detailed class, method, and property listings for each library.

The reference home page, represented in `content/reference.aspose.net/home/en/_index.md`, introduces this portal and indicates that it is the primary destination for high-level API signatures and usage notes.
Developers can navigate by product family and namespace to locate the types relevant to their applications.

The live reference experience is available at [reference.aspose.net](https://reference.aspose.net/).

## Organization by Product and Namespace

API references are organized first by product family—such as Aspose.Words, Aspose.Cells, Aspose.PDF, Aspose.BarCode, and others—and then by namespace.
Within each namespace, the portal lists classes, interfaces, enums, and other types along with their members.

This structure is visible in the repository under paths like `content/reference.aspose.net/barcode/en/`, which contain markdown for individual types.
Each type page includes metadata, inheritance information, and links to related types.

The organization mirrors standard .NET documentation conventions, making it easy for developers familiar with MSDN-style references to navigate.

## Relationship to Product Documentation

The reference portal works alongside the main documentation on [docs.aspose.com](https://docs.aspose.com/).
Conceptual and how-to articles in the docs often link to specific reference pages for deeper technical details.

Conversely, reference pages may link back to tutorials or conceptual overviews when additional context is helpful.
This bidirectional linking encourages developers to move between conceptual understanding and low-level API details as needed.

Together, the docs and reference portals provide a complete picture of how to use Aspose APIs effectively in real applications.
